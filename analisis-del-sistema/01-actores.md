# Actores del sistema

| Actor | ¿Qué necesita realizar? |
|---|---|
| Cliente | Buscar servicios y prestadores, consultar información, publicar trabajos, revisar propuestas, contratar, realizar pagos y consultar sus contrataciones. |
| Prestador de servicios | Ofrecer servicios, registrar y actualizar sus servicios, consultar trabajos publicados, enviar propuestas y gestionar sus contrataciones. |
| Administrador | Administrar la plataforma, usuarios, categorías y publicaciones. |
| Pasarela de pago | Procesar los pagos relacionados con las contrataciones. |
| Servicio de notificaciones | Enviar avisos sobre propuestas, contrataciones y cambios de estado. |
| Servicio de ubicación | Gestionar información de ubicación para facilitar la búsqueda de prestadores y servicios. |

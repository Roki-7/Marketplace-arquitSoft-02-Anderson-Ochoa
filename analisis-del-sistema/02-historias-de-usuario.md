# Historias de usuario

| ID | Historia de usuario |
|---|---|
| HU01 | Como cliente, quiero buscar y consultar servicios y prestadores, para encontrar el servicio que necesito. |
| HU02 | Como prestador de servicios, quiero registrar y gestionar los servicios que ofrezco, para que los clientes puedan encontrarlos. |
| HU03 | Como cliente, quiero publicar un trabajo que necesito realizar, para recibir propuestas de prestadores interesados. |
| HU04 | Como prestador de servicios, quiero enviar una propuesta o cotización a un trabajo publicado, para tener la posibilidad de ser contratado. |
| HU05 | Como cliente, quiero revisar y aceptar una propuesta, para contratar al prestador seleccionado. |
| HU06 | Como cliente, quiero consultar mis contrataciones y su estado, para conocer el avance de los servicios solicitados. |

# Requisitos funcionales

| ID | Requisito funcional |
|---|---|
| RF01 | El sistema debe permitir buscar servicios y prestadores mediante criterios de búsqueda. |
| RF02 | El sistema debe permitir consultar la información, disponibilidad y perfil de los prestadores. |
| RF03 | El sistema debe permitir registrar y actualizar los servicios ofrecidos por un prestador. |
| RF04 | El sistema debe permitir al cliente publicar una solicitud de trabajo. |
| RF05 | El sistema debe permitir al prestador consultar trabajos publicados y enviar propuestas o cotizaciones. |
| RF06 | El sistema debe permitir al cliente consultar y comparar las propuestas recibidas. |
| RF07 | El sistema debe permitir aceptar una propuesta y registrar la contratación del servicio. |
| RF08 | El sistema debe permitir consultar las contrataciones realizadas y su estado. |

## Relación entre historias de usuario y requisitos funcionales

| Historia de usuario | Requisitos funcionales relacionados |
|---|---|
| HU01 - Buscar y consultar servicios | RF01, RF02 |
| HU02 - Gestionar servicios | RF03 |
| HU03 - Publicar trabajo | RF04 |
| HU04 - Enviar propuesta | RF05 |
| HU05 - Revisar y aceptar propuesta | RF06, RF07 |
| HU06 - Consultar contrataciones | RF08 |
